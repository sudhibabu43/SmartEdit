Learn More
==========
We are working hard to expand this user guide and to improve SmartEdit Video Editor, but if you are
stuck and don't know where to turn, SmartEdit has several sources for additional information.

 #. SmartEdit has several `YouTube Tutorials <https://www.youtube.com/playlist?list=PLymupH2aoNQNezYzv2lhSwvoyZgLp1Q0T>`_ available to help you learn more.
 #. SmartEdit has a `Reddit User Community <https://smartedit.org/forum>`_ dedicated to users helping users, answering questions, and discussing video editing and SmartEdit topics.
 #. If you would like to help improve this User Guide, `view source on GitHub <https://github.com/SmartEdit/smartedit-qt/tree/develop/doc>`_.
 #. If you have discovered a new bug, please `Report a Bug <https://www.smartedit.org/issues/new/>`_.
 #. If you need professional support, you can open a ticket by sending an message to support@smartedit.org
    or `Schedule a call <https://calendly.com/smartedit-support/desktop>`_.
