# SmartEdit Dependencies

| Dependency | Purpose | Used By | External/Open Source |
|------------|---------|---------|----------------------|
| Qt (PyQt5) | GUI Desktop Interface | UI | Yes |
| OpenCV     | Video Analysis, Scene Detection | Analysis | Yes |
| FFmpeg     | Media decoding/encoding, Playback | Playback/Export | Yes |
| JUCE       | Audio Engine | `libsmartedit-audio` | Yes |
| Godot      | Experimental Binding (Leftover) | `libsmartedit` | Yes |
